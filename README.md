## 📋 О проекте

**Рабочий дом** — это проект помощи людям, оказавшимся в сложной жизненной ситуации: бездомным, беженцам, освободившимся из мест лишения свободы, зависимым в ремиссии, обманутым на вахте, семьям с детьми и другим категориям нуждающихся.

### 🔑 Ключевые возможности
- **Бесплатное проживание** в рабочих домах по всей Московской области
- **Трёхразовое горячее питание**
- **Ежедневные выплаты** от 2 000 ₽/день
- **Заселение в день обращения** (круглосуточно)
- **Принимаем без документов** — помогаем с восстановлением
- **Без предоплат и скрытых платежей**

## 🛠 Технические характеристики

### Frontend
- **Тип:** Статический сайт (HTML/CSS/JS)
- **Шрифты:** Roboto через CDN (jsdelivr.net)
- **Изображения:** Все в формате **WebP** для оптимизации загрузки
- **Адаптивность:** Полностью адаптивный дизайн (mobile-first)
- **CSS-препроцессор:** Не используется (ванильный CSS)

### SEO-оптимизация
✅ **Meta-теги:**
- Title, Description, Keywords для каждой страницы
- Geo-теги (RU-MOW, Москва)
- Open Graph (OG) для социальных сетей
- Twitter Card
- Canonical URLs

✅ **Schema.org разметка:**
- `Organization` — информация о компании
- `LocalBusiness` — локальный бизнес
- `JobPosting` — вакансии с зарплатой
- `Article` / `BlogPosting` — статьи блога
- `BreadcrumbList` — навигационные цепочки
- `Person` — персоны в отзывах

✅ **Другие SEO-фичи:**
- Sitemap.xml со всеми URL
- Robots.txt с директивами
- ЧПУ (URL без .html благодаря .htaccess)
- Микроразметка для расширенных сниппетов

### Аналитика
| Сервис | ID / Конфигурация |
|--------|-------------------|
| **Яндекс.Метрика** | 99128157 (с Webvisor, clickmap, trackLinks) |
| **Google Search Console** | Верификация через HTML-файл |

### Антибот-система (JSSter v11.0)
Встроенная система защиты от ботов с множественными проверками:

**Проверки активности:**
- Активность 15/30/45/60 секунд
- Скролл 25/50/75% страницы
- Движение мыши (траектория, кривизна)
- Касания (touch pressure)
- keystroke dynamics

**Автоматизация:**
- WebDriver детекция
- Headless-браузеры
- Chrome Runtime проверка
- Hardware concurrency (2-32 ядер)
- Device Memory (≥0.5 GB)

**Fingerprinting:**
- Canvas fingerprinting
- WebGL анализ
- Audio Context
- Шрифты (минимум 5)

**Timing-атаки:**
- Timer precision (≥10 μs)
- First interaction delay (≥100 ms)
- Time consistency (макс. скачок 5000 ms)

**Другие проверки:**
- Honeypot-поля (невидимые для людей)
- Iframe detection
- Screen orientation
- Network information API
- Battery API
- Codec support
- RAF timing

> ⚠️ **Важно:** Цели `active15/active30/active45/active60/scroll25/scroll50/scroll75` должны быть созданы в интерфейсе Яндекс.Метрики.

### URL Rewriting (.htaccess)
```apache
# 1. Внешний редирект 301: /page.html → /page
# 2. Внутренняя перезапись: приоритет файлу .html над папкой
# 3. Если нет .html файла — отдаём содержимое папки
```

## 🚀 Развёртывание

### GitHub Pages
Проект настроен для автоматического развёртывания через GitHub Actions:

1. Пуш в ветку `main` запускает workflow
2. Артефакт загружается на GitHub Pages
3. Сайт доступен по адресу: `https://username.github.io/silver-goggles/`

**Workflow файл:** `.github/workflows/pages.yml`

### Локальный запуск
```bash
# Вариант 1: Python
python -m http.server 8000

# Вариант 2: Node.js (npx)
npx serve .

# Вариант 3: PHP
php -S localhost:8000
```

### Хостинг (Apache)
1. Загрузить все файлы на хостинг
2. Убедиться, что `.htaccess` активен (mod_rewrite включён)
3. Проверить права доступа (755 для папок, 644 для файлов)

## 🔧 Техническое обслуживание

### Обновление контента
1. Отредактировать соответствующий HTML-файл
2. Обновить дату модификации в `<lastmod>` sitemap.xml
3. Закоммитить изменения
4. GitHub Actions автоматически развернёт обновления

### Добавление нового города
1. Скопировать шаблон из существующего файла в `/adresa/`
2. Заменить название города и контент
3. Добавить URL в `sitemap.xml`
4. Закоммитить и запушить

### Добавление вакансии
1. Создать новый файл в `/vakansii/`
2. Добавить Schema.org `JobPosting` разметку
3. Добавить ссылку на главную страницу вакансий
4. Обновить `sitemap.xml`
